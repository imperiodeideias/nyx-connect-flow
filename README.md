# NYX: Real Time Insight

# PRODUCT REQUIREMENTS DOCUMENT - PRD

# PROJETO

Landing Page NYX Tecnologia
Soluções Digitais + IoT para Saúde

# OBJETIVO

Criar uma landing page comercial, enxuta e altamente orientada à conversão para a NYX Tecnologia.

A página será acessada majoritariamente por dispositivos móveis, inclusive através de:

- QR Codes
- eventos
- materiais impressos
- apresentações comerciais
- campanhas
- links enviados diretamente para leads

Portanto, desenvolver MOBILE FIRST.

O objetivo principal é:

1. apresentar rapidamente a proposta de valor da NYX
2. despertar interesse em Hospital Inteligente e IoT
3. dar protagonismo ao tracker
4. mostrar algumas aplicações práticas no ambiente hospitalar
5. apresentar o newcheck como parte do ecossistema
6. captar o lead
7. gerar contato comercial

A landing page deve ser SUCINTA.

Não transformar esta página em uma cópia do site institucional.

Não apresentar todos os módulos, recursos e detalhes técnicos disponíveis nos materiais.

A prioridade é gerar compreensão + interesse + contato.
